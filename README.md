# Stickshot - releases

APK downloads and official website for **Stickshot**, a ragdoll stick-figure brawler for Android.

**Website:** https://judecjz.github.io/stickshot-releases/

**Install:** open the [latest release](https://github.com/JudeCJz/stickshot-releases/releases/latest) on your phone, download the `.apk` and open it (allow installing from your browser if Android asks).

The game checks this page when you open the main menu and shows an **UPDATE** button when a newer version is out.
